色のついた線は、関係です。

家系図のエッジは飾りではありません。引用関係を分析して判定した、論文どうしの「関係の種類」を、 色と線種で表しています。全6種の意味を、ビューアで実際に出る線そのもので解説します。

6つの関係

親 → 子（古い論文 → 新しい論文）の向きで読みます

  • 置換 supersedes

    旧手法を置き換える「決定版」。同じ土俵で明確に上回り、以後はこちらが本流になる。

    例: FlashAttention → FlashAttention-2

  • 後継 successor

    同じ系統を素直に受け継ぐ、次の世代。置換ほど決定的ではないが直系の続き。

    例: A ConvNet for the 2020s → ConvNeXt V2

  • 拡張 extends

    土台はそのままに、新しい能力や適用範囲を足す。手法を別ドメインへ広げる場合など。

    例: Transformer → Vision Transformer (ViT)

  • 成分分析 ablation

    構成要素を抜き差しして、どこが効いているかを測る検証的な関係。多くは論文内で行われるため、論文間のエッジとしては稀。

  • 比較 baseline

    性能比較の「物差し」として引かれる対照。新手法が旧手法をベースラインとして引用するケース。最も弱い結びつき。

  • 対立 contrasts

    設計思想が真っ向から異なる、対抗する系統。同時代の別アプローチ（例: CNN と Transformer）どうしなど。

どう判定しているか

論文を arXiv・Semantic Scholar・OpenAlex から収集し、品質シグナルで絞り込んだうえで、 引用グラフ（どの論文がどれを引いているか）をたどります。各エッジの関係種別は、 引用文脈や引用の意図、年代・引用数の関係を手がかりに自動判定し、 曖昧なものは LLM が補助します（LLM が使えないときは決定的なヒューリスティックにフォールバック）。 詳しい段階構成・スコアリングの正式な定義は、下記の設計ドキュメントを参照してください。
