# 1. エグゼクティブサマリー

AI・機械学習分野では、arXivのcs.LGカテゴリだけで月間3,000件超の論文が投稿されており、研究者が手動で追跡することは事実上不可能な状況にある。本レポートでは、論文を自動収集し、学会採択ステータス・GitHub Stars・引用速度などの品質シグナルに基づいてフィルタリングするツール「PaperPilot」の事業機会を分析する。
学術研究開発市場は2025年時点で約5,808億ドル規模（CAGR 8.7%）であり、AI駆動リサーチツール（Elicit、Consensus等）が急成長している。しかし、「キーワード指定 → 定期バッチ収集 → 品質フィルタリング → CSV/Slack通知」に特化した軽量OSSパイプラインは市場に存在しない。特に日本語対応は未開拓である。
PaperPilotは、**5段階のフィルタリングパイプライン**（ルールベース → メトリクススコアリング → Embedding類似度 → LLMリランキング）により500件を10件に絞り込む。月間運用コストは約¥900〜1,500で、Elicit Pro（$49/月）の1/4以下に抑えられる。
