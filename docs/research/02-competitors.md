# 3. 競合分析

## 3.1 競合マップ
既存ツールは大きく3カテゴリに分類できる。
### 3.1.1 AI論文発見・分析ツール（セマンティック検索型）

| ツール | ユーザー | 価格 | 強み | 弱み |
|---|---|---|---|---|
| Elicit | 200万人超 | $0〜$49/月 | 1.38億論文、系統的レビュー自動化 | Alertsは$49/月〜、日本語非対応 |
| Consensus | — | 無料〜有料 | Yes/No合意度メーター、2億論文 | バイナリ的回答に特化 |
| SciSpace | — | $20/月〜 | PDF読解、AIチャット、執筆支援 | 無料版制限が厳しい |
| Paperguide | — | $12/月〜 | 検索・分析・執筆の統合 | 新興サービス |

### 3.1.2 引用ネットワーク・論文発見ツール

| ツール | 価格 | 強み | 弱み |
|---|---|---|---|
| Connected Papers | 無料〜有料 | 引用グラフの可視化 | シード論文が必要 |
| ResearchRabbit | 無料 | 引用ネットワークからの推薦 | バッチ収集不可 |
| Litmaps | 無料〜$12/月 | 引用マップ＋共著者検索 | データ連携が弱い |
| Semantic Scholar | 無料 | 2億論文、TLDR要約、API | パイプライン機能なし |
| arxiv-sanity-lite | 無料（OSS） | arXiv論文のパーソナライズド推薦、SVM分類 | メンテナンス低下、UIが簡素 |

### 3.1.3 文献管理ツール（リファレンスマネージャー型）

| ツール | 価格 | 強み | 弱み |
|---|---|---|---|
| Zotero | 無料（OSS） | 1クリック取り込み、10,000+引用スタイル | 自動収集機能なし |
| Mendeley | 無料 | PDF自動読み込み、書誌情報抽出 | Elsevier依存、日本語弱い |
| Paperpile | $2.99/月〜 | Google連携、引用論文の発見 | Chrome環境に依存 |
| EndNote | 有料（買切り） | 6,000+引用スタイル、AI要約 | 高価、学習コスト高 |

## 3.2 競合の空白領域（ホワイトスペース）
調査の結果、以下の5つの領域に明確なギャップが存在する。

| 空白領域 | 説明 | 事業機会 |
|---|---|---|
| キーワード定期バッチ収集 | 毎日/毎週、新着をCSVで届ける機能に特化したツールがない | ★★★ |
| 複数ソースの統合 | arXiv + S2 + OpenAlexの横断検索OSSパイプラインが不在 | ★★★ |
| 品質シグナル統合フィルタ | 学会採択・GitHub Stars等を統合したスコアリング | ★★★ |
| 日本語対応 | 主要AIツールはほぼ英語UI。日本語要約は未開拓 | ★★☆ |
| LLMトリアージ | AIによる「読むべき優先度」自動判定は未成熟 | ★★☆ |

## 3.3 Elicit詳細分析（主要ベンチマーク）

| 項目 | 詳細 |
|---|---|
| ユーザー数 | 200万人以上 |
| 論文DB | 1.38億論文（Semantic Scholar）+ 54.5万臨床試験 |
| Basic（無料） | 5,000クレジット（一度のみ・更新なし） |
| Plus | $12/月 — レポート4件/月、検索無制限 |
| Pro | $49/月 — レポート12件/月、Alerts 10件 |
| Team | $79/ユーザー/月 — レポート20件/月、共同編集 |
| 強み | 構造化データ抽出、引用付きレポート生成 |
| 弱み | 無料枠が使い切り型、定期監視はPro以上、日本語非対応 |

## 3.4 SWOT分析

|   | プラス要因 | マイナス要因 |
|---|---|---|
| 内部 | 【強み】OSS・無料・ローカル実行可能。品質シグナル統合スコアは競合にない独自機能。日本語対応で国内市場を先行獲得可能。 | 【弱み】開発リソースが限定的（個人/小規模チーム想定）。ブランド認知ゼロからのスタート。UI/UXの洗練度でSaaS勢に劣後。 |
| 外部 | 【機会】AI論文の爆発的増加で自動化ニーズが拡大。Elicit等は$49/月〜で価格障壁あり。日本語対応ツールの空白。 | 【脅威】Elicit/Consensusが同機能を追加する可能性。arXiv APIのレート制限強化。LLM APIコスト変動。 |
