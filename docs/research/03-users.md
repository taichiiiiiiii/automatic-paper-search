# 4. ターゲットユーザー

## 4.1 ペルソナ定義
ペルソナA: 大学院生・ポスドク（国内）
年齢24〜35歳。週に数百件の新着論文を追えない。英語論文の効率的なスクリーニングが必要。ツール予算は無料〜月1,500円程度。毎朝新着CSVが届き、Excelで確認できる形式を求める。
ペルソナB: 企業研究者・R&Dエンジニア
年齢28〜45歳。競合技術の動向監視が主目的。特定技術（LoRA、MoE等）の最新論文を漏れなくキャッチしたい。月5,000円〜の予算。Slack通知 + ダッシュボード + AIによる優先度判定を求める。
ペルソナC: 独立系AIリサーチャー・ブロガー
年齢25〜40歳。毎週の論文サーベイ記事の執筆効率化が目的。無料〜月2,000円の予算。カテゴリ別の自動収集 + AI要約 + Markdown出力を求める。
