# 8. リスクと対策

| リスク | 影響度 | 対策 |
|---|---|---|
| arXiv APIのレート制限強化 | 高 | 複数ソースへの分散、キャッシュ戦略 |
| Elicit等が同機能を追加 | 中 | OSS・ローカル実行・品質シグナル統合で差別化 |
| LLM API費用の高騰 | 中 | Ollama等ローカルLLMへの切り替えオプション |
| 論文著作権の問題 | 低 | メタデータのみ取り扱い、全文保存は行わない |
| ユーザー獲得の伸び悩み | 中 | OSS公開でロングテール的にユーザー獲得 |
