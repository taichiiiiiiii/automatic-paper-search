## 学会の論文一覧

対象: `/<conf>/`（`apps/web/app/[conf]/page.tsx`、`components/catalog/*`、`lib/catalog-*.ts`）と JavaScript なしの `/<conf>/paper-links/` ・ `/<conf>/paper-links/<n>/`。
点検日 2026-10-12。ローカルで `apps/web/out` を配信し、ヘッドレスブラウザで 375px（スマホ）と 1280px（PC）を確認した。大きい学会は icml-2026（6,552 本）、neurips-2025（5,286 本）、cvpr-2026（4,068 本）、iclr-2025（3,703 本、要旨 82%）。

### 計測（変更前 → 変更後）

| 項目 | 変更前 | 変更後 | 備考 |
| --- | --- | --- | --- |
| 375px でのページ幅（`scrollWidth`） | 948px（横スクロールが出る） | 375px | 全 5 学会で確認 |
| 375px で常時画面に残る絞り込み欄の高さ | 163px（sticky） | 0px（スマホでは sticky にしない。PC は従来どおり sticky） | 画面の 2 割を占めていた |
| 検索欄 1 打鍵あたりの描画（icml-2026、中央値） | 12.3ms（検索なし）/ 23ms（検索中） | 3.1ms / 3.7ms | 入力イベント 1 回の同期描画の時間。開発用 Mac のヘッドレス Chrome |
| 最初の 30 件が出るまで（ローカル、回線制限なし） | 0.47s | 0.37s | データは同じ |
| 本番 icml-2026 の転送量 | 2.46MB（うち `papers.json` 1.67MB、br 圧縮。展開後 7.0MB） | 変更なし | 9Mbps・60ms の回線で最初の結果まで 3.8s |
| 表示する行 | 30 件ずつ（「さらに表示」） | 変更なし | DOM は 9k 件を一度に描かないので仮想リストは不要 |

検索の 1 打鍵は、debounce（180ms）を待つ間も毎回 6〜9k 行の絞り込み・並べ替え・タグ集計をやり直していた。各値を入力ごとに `useMemo` で覚え、行ごとの小文字化した検索対象文字列を `WeakMap` で 1 回だけ作るようにした。debounce 後の検索は `useDeferredValue` で中断できる描画にした。

### 直したこと（高・中）

| 重要度 | 問題 | 対応 |
| --- | --- | --- |
| 高 | 375px で横スクロールが出る。`<fieldset>` の既定の `min-inline-size: min-content` のせいで、タグの横スクロール行が 948px に広がっていた。あわせて並び替えの `<select>` が最長の選択肢「新着順（arXiv ID がない学会では使えません）」の幅になり、37px はみ出していた | fieldset と select に `min-w-0`。使えない新着順の表示を「新着順（arXiv ID なし）」に短くし、理由は select の title に書いた |
| 中 | スマホで絞り込み欄（163px）が常に上に残り、一覧が見づらい | sticky を `sm` 以上だけにした。スマホは「↑ Top」で検索欄に戻れる |
| 中 | 打鍵のたびに全件を絞り込み直していた（上の計測） | `useMemo`、検索対象文字列の作り置き、`useDeferredValue` |
| 中 | 複数語の検索が「完全に同じ並び」でしか当たらない（"video diffusion" → 29 件） | 空白（全角も含む）で語に分け、すべての語を含む行を出す。強調表示も語ごと。1 語の検索は従来と同じ |
| 中 | 日本語で検索すると「条件に一致する論文がありません」とだけ出る（タイトルと要旨は英語） | 0 件のとき、検索語・「英語のキーワードで検索してください」・複数語の注意・ほかの絞り込みが効いていることを表示する。入力欄の例も「英語で検索（例: diffusion video）」にした |
| 中 | 件数表示が 2 種類（「30 / 548 件を表示（全 6552 件）」と「548 / 6552 件」）あり、最初の数の意味が場合によって違った | 「548 件が該当（全 6,552 件） · 先頭 30 件を表示中」に統一した（`lib/catalog-status.ts`） |
| 中 | 全件 Poster の学会（icml-2026）で「all 6552」「Poster 6552」の意味のない 2 つのボタンと「0 Oral」が出る | 種類が 1 つだけならボタンを隠し、Oral 0 件の数字も出さない（URL で種類を指定したときは、外せるようにボタンを出す）。「all」は「すべて」に変えた |
| 中 | 要旨のない論文が多い学会（iclr-2025 は 18%、cvpr-2026 は 28%）で、それを外す手段がない | 「要旨あり」ボタンを追加した（URL `abs=1`、要旨のない行がある学会だけ）。冒頭に「要旨あり N」も表示する |
| 中 | 一覧のページから他の学会へ移れない（トップに戻るしかない） | 冒頭に「他の学会を見る」（`<details>`。JS なしでも開ける）を追加した。今の学会には `aria-current` を付けた |
| 中 | Oral/Poster の札がカードの高さいっぱいに伸びて、縦長の空の枠に見える。スマホでは札の列が約 60px を取り、タイトルが狭い | 札を `self-start` にした。スマホでは札をタイトルの上に置く |
| 中 | 詳細を開いても著者が 1 行で切れたまま | 選んだカードでは著者を全員表示する |
| 中 | 選んだカードの背景（surface-2）の上で、12px のリンク（OpenReview / PDF など）のコントラストが 4.17:1 で 4.5:1 に届かない | 選んだカードのリンクを accent-strong（6.95:1）にし、下線を付けた |
| 中 | 「+N タグ」の `aria-controls="tag-chips-tail"` が存在しない id を指していた。「内容を見る」が 30 個同じ名前で並び、読み上げで区別できない | 残りのタグを包む要素に `useId` の id を付けた。開くボタンを「詳細を開く」（閉じるボタン「詳細を閉じる」と対）に変え、`aria-describedby` で論文タイトルを結び付けた |
| 中 | JS なしの一覧: 見出しが slug（`icml-2026`）のまま。タイトルがリンクに見えない（下線なし・本文と同じ色）。ページ番号が小さくて押しにくい | 表示名（ICML 2026）にした。タイトルに下線を付けた。ページ送りに「← 前へ / 次へ →」を足し、44px 以上の押せる大きさにした。行の HTML は変えていない（parity テストはそのまま通る） |
| 中 | 書き出しボタンが並び替えより前にあり、主な操作の間に割り込んでいた | ツールバーの順を「フィルタ解除 → 並び替え → BibTeX / CSV / URL」にした。書き出しボタンには件数入りの `aria-label` を付けた |

### 直したこと（低）

| 問題 | 対応 |
| --- | --- |
| 読み込み中は「論文一覧を読み込み中…」だけで、件数も進み具合も分からない（icml-2026 は 9Mbps で約 4 秒） | 冒頭の論文数を build 時の `conferences.json` から最初から出す。読み込み中の行に「6,552 本の論文一覧を読み込み中… 3.2 MB」と受信量を出す（`fetchConferencePapers(slug, { onProgress })`、約 256KB ごとに更新） |
| 全カードのタイトルが accent（赤）で、画面が重い | カードのタイトルは ink（本文色）、hover で accent-strong |
| 「続きを読む」と「内容を見る」の 2 つの操作が離れていて、違いが分からない | 要旨のすぐ下に並べ、名前を「要旨をもっと見る / たたむ」（その場で広げる）と「詳細を開く」（全文の要旨と系譜。title で説明）にした |
| PC で sticky の絞り込み欄の下に、選んだカードやフォーカスが隠れる | カードに `scroll-margin-top`（sm 以上で 12rem）。選んだカードの上端は絞り込み欄の下（1280px で 192px > 138px）に来る |
| 「+N タグ」で開いたタグを閉じられない。タグ候補は上位 18 個だけ | 1 つのボタンで開閉（`aria-expanded`）。候補は全タグ（icml-2026 は 61）。閉じていても選択中のタグは見える |
| acl-2026 の見出しと切り替えが slug のまま | `CATALOG_COPY` に ACL 2026 を追加 |
| 検索が語形や表記ゆれを吸収しない | ハイフン・ダッシュ・スラッシュを空白とみなす（"self-supervised" と "self supervised"）。5 文字以上で -s / -es で終わる語は単数形でも当たる（"transformers" → "transformer"） |
| 「タイトル A→Z」で、LaTeX や引用符で始まる約 200 本が "A" より前に並ぶ | 並べ替えのときだけ、先頭の記号と LaTeX コマンドを無視する |
| 選んだカードの「系譜での位置」リンクと要旨の出典のライセンスリンクが accent（surface-2 の上で 4.17:1） | accent-strong と下線にした |
| 詳細を閉じるのがマウスだけ。直接 `?paper=` で開いたときに閉じると、フォーカスが body に落ちる | Esc で閉じる（入力欄の中と IME 変換中は除く。閉じるボタンに `aria-keyshortcuts`）。閉じたあとはそのカードの「詳細を開く」にフォーカスを戻す |
| 読み込み中に冒頭が「— Oral」と出る | Oral の件数が分かって 1 以上のときだけ出す |
| `globals.css` の `a { color: accent }` は layer の外にあり、Tailwind の `text-*`（layer の中）より強い。このため `<a className="text-ink">` などの色指定が効いていなかった（上の「タイトルの色」と「選んだカードのリンクのコントラスト」も、最初の修正では実際には変わっていなかった） | リンクの色を `catalog.module.css` の `.titleLink` / `.strongLink` / `.mutedLink`（layer の外、`a` より詳細度が高い）で指定した。build したページで計測し、タイトル 16.8:1、選んだカードのリンク 6.95:1 |
| JavaScript が無効だと、`<noscript>` の案内の下に「読み込み中…」と「— タグ」が出続ける | 読み込み中の表示はスクリプトが動き出してから出す。タグ数は分かってから出す |
| 検索直後、件数が古いまま新しい検索語だけが表示される一瞬がある | 検索語の表示と 0 件の説明も、件数と同じ遅延値（`useDeferredValue`）から作る |

### 残したこと（範囲外）

- `papers.json` を一覧用と要旨用に分けること。最初の表示は速くなるが、`buildPagesCli` の出力形式、promote の refresh chain、`copy-data`、parity テストのすべてが変わり、すべての学会の公開データを作り直すことになる。UI の作業ではなく、データ形式の変更として別の項目にする（読み込み中の表示は上で改善した）。
- 要旨の出典表示（CC BY の帰属表示）の長さ。形式は 51（規約と法務）で決めたもので、短くしてよいかは法務の判断。
- トラック（分野）・「コードあり」の絞り込み。`papers.json` にその列がない（`github_stars` はすべて 0）。データの収集を足すまでは作れない。
- JS なしの一覧の 1 ページの大きさ。計測したら gzip 後 237KB（icml-2026 の 1 ページ目、3,000 行）で、スマホでも問題にならない。直す必要はない。
- 「フィルタ解除」は並び替えを戻さない。並び替えは絞り込みではないので、そのままにした。

### UI で確かめた操作（build 済みのサイト、375px と 1280px）

ローカルの `apps/web/out` を `127.0.0.1` で配信し、ヘッドレス Chrome で実際にクリックや入力をして確かめた。どの幅でも同じ結果だった。

| 操作 | 結果 |
| --- | --- |
| 英語の検索 "video diffusion" | 53 件、語ごとに強調 120 か所、URL `?q=video+diffusion` |
| 日本語の検索 "拡散モデル" | 0 件の説明（英語で検索するよう案内）と「フィルタを解除」 |
| Backspace で検索語を消す / 「フィルタを解除」 | 全 6,552 件に戻り、URL も空になる |
| タグ RL | 940 件、`?tags=RL`、`aria-pressed=true` |
| 「+53 タグ」/「タグをたたむ」 | 61 個 / 8 個 |
| 並び替え「タイトル A→Z」 | `sort=title` |
| 「さらに表示」 | 先頭 60 件 |
| 「要旨をもっと見る」 | `aria-expanded=true` |
| 「詳細を開く」 | `?paper=` が付き、見出しにフォーカス、全文の要旨（1,106 字） |
| Esc / 「詳細を閉じる」/ ブラウザの戻る・進む | 閉じてそのカードの「詳細を開く」にフォーカスが戻る。進むで開き直す |
| `?paper=` で直接開いて Esc | URL から `paper` が消え、フォーカスが戻る |
| URL からの復元 `?q=gaussian+splatting&type=Oral&tags=3D&sort=title&abs=1` | 3 件。検索欄・Oral・3D・並び替え・要旨ありがすべて復元 |
| BibTeX / CSV | `iclr-2025-papers-2026-10-11.bib`（81 件）と `.csv`（81 行 + 見出し）が保存される |
| URL をコピー | 「URL をコピーしました」、クリップボードに今の URL |
| 他の学会を見る → ICLR 2025 | `/iclr-2025/` に移る |
| 系譜での位置（eccv-2024 の 1 行に Mixture of Experts の節点の arXiv ID を入れた検証用データ） | 「Mixture of Experts の系譜で見る →」から `/themes/?theme=mixture-of-experts&focus=…` に移る |
| JS なしの論文リンク一覧 | 次へ → 2 ページ目、3 → 3 ページ目、前へ → 2 ページ目、「ICML 2026 の通常版」→ `/icml-2026/` |
