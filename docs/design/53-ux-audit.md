# 53 UI/UX 点検（2026-10-12）

ページの担当ごとに節を分ける。各節は単独で読めるようにする。

## トップ・共通

対象: トップ（`/`）、全ページ共通のヘッダー・フッター、`/how-it-works/`（仕組み・出典・プライバシー）、404。テーマ依頼フォームは `/themes/` の中にあるので、テーマの節で扱う。

方法: 静的書き出し（`apps/web/out`）を手元で配信し、ブラウザで幅 375px（スマホ）と 1280px（PC）を表示して確認した。あわせて、タップ領域の大きさ・見出しの構成・読み込むファイルとサイズ・CLS・メタタグを DOM と Performance API で測り、色のコントラストはデザイントークン（OKLCH）から WCAG の比を計算した。

### 残したもの（重要度 低）

- 系譜の棚のために、トップで `lineage-quality-v1.json`（約 126 KB、圧縮前）を取得している。棚に使うのは数行だけ。公開の可否はブラウザで確かめる約束（SCR-11）なので今回は変えていない。ビルド時に棚の行だけを書き出す小さな JSON にすれば減らせる。
- ダークモードがない（`color-scheme: light` で固定）。トークンが OKLCH なので、`prefers-color-scheme` のブロックを足せば対応できる。
- `--color-accent`（4.54:1）は、白に近い背景では AA ぎりぎりで、`--color-surface-2` の上では下回る。小さい文字のリンクには `--color-accent-strong` を使うよう、ほかのページでも順にそろえたい。
- 仕組みページのパンくずが、0.72rem の英大文字風の等幅のまま（「PAPERPILOT / 仕組み」）。
- 仕組みページはほぼ系譜の線の説明で、サイト全体の案内（検索・学会カタログ・テーマ）がない。トップの 1 行の案内で当面は足りる。
- 「検索した後は？」の折りたたみは、家系図が論文の詳細から開ける場合があることなど、初めての人には説明が多い。利用の様子を見て短くする。
- 例のチップは高さ約 30px。WCAG 2.2 の 24px は満たすが、44px にはしていない。
- 本文中のデータ出典のリンク（フッター）は高さ 17px。文中のリンクは WCAG 2.5.8 の対象外。
