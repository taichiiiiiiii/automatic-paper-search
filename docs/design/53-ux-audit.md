## 学会の論文一覧

対象: `/<conf>/`（`apps/web/app/[conf]/page.tsx`、`components/catalog/*`、`lib/catalog-*.ts`）と JavaScript なしの `/<conf>/paper-links/` ・ `/<conf>/paper-links/<n>/`。
点検日 2026-10-12。ローカルで `apps/web/out` を配信し、ヘッドレスブラウザで 375px（スマホ）と 1280px（PC）を確認した。大きい学会は icml-2026（6,552 本）、neurips-2025（5,286 本）、cvpr-2026（4,068 本）、iclr-2025（3,703 本、要旨 82%）。

### 計測（変更前 → 変更後）

| 項目 | 変更前 | 変更後 | 備考 |
| --- | --- | --- | --- |
| 375px でのページ幅（`scrollWidth`） | 948px（横スクロールが出る） | 375px | 全 5 学会で確認 |
| 375px で常時画面に残る絞り込み欄の高さ | 163px（sticky） | 0px（スマホでは sticky にしない。PC は従来どおり sticky） | 画面の 2 割を占めていた |
| 検索欄 1 打鍵あたりの描画（icml-2026、中央値） | 12.3ms（検索なし）/ 23ms（検索中） | 3.1ms / 3.7ms | 入力イベント 1 回の同期描画の時間。開発用 Mac のヘッドレス Chrome |
| 最初の 30 件が出るまで（ローカル、回線制限なし） | 0.47s | 0.37s | データは同じ |
| 本番 icml-2026 の転送量 | 2.46MB（うち `papers.json` 1.67MB、br 圧縮。展開後 7.0MB） | 変更なし | 9Mbps・60ms の回線で最初の結果まで 3.8s |
| 表示する行 | 30 件ずつ（「さらに表示」） | 変更なし | DOM は 9k 件を一度に描かないので仮想リストは不要 |

検索の 1 打鍵は、debounce（180ms）を待つ間も毎回 6〜9k 行の絞り込み・並べ替え・タグ集計をやり直していた。各値を入力ごとに `useMemo` で覚え、行ごとの小文字化した検索対象文字列を `WeakMap` で 1 回だけ作るようにした。debounce 後の検索は `useDeferredValue` で中断できる描画にした。

### 直したこと（高・中）

| 重要度 | 問題 | 対応 |
| --- | --- | --- |
| 高 | 375px で横スクロールが出る。`<fieldset>` の既定の `min-inline-size: min-content` のせいで、タグの横スクロール行が 948px に広がっていた。あわせて並び替えの `<select>` が最長の選択肢「新着順（arXiv ID がない学会では使えません）」の幅になり、37px はみ出していた | fieldset と select に `min-w-0`。使えない新着順の表示を「新着順（arXiv ID なし）」に短くし、理由は select の title に書いた |
| 中 | スマホで絞り込み欄（163px）が常に上に残り、一覧が見づらい | sticky を `sm` 以上だけにした。スマホは「↑ Top」で検索欄に戻れる |
| 中 | 打鍵のたびに全件を絞り込み直していた（上の計測） | `useMemo`、検索対象文字列の作り置き、`useDeferredValue` |
| 中 | 複数語の検索が「完全に同じ並び」でしか当たらない（"video diffusion" → 29 件） | 空白（全角も含む）で語に分け、すべての語を含む行を出す。強調表示も語ごと。1 語の検索は従来と同じ |
| 中 | 日本語で検索すると「条件に一致する論文がありません」とだけ出る（タイトルと要旨は英語） | 0 件のとき、検索語・「英語のキーワードで検索してください」・複数語の注意・ほかの絞り込みが効いていることを表示する。入力欄の例も「英語で検索（例: diffusion video）」にした |
| 中 | 件数表示が 2 種類（「30 / 548 件を表示（全 6552 件）」と「548 / 6552 件」）あり、最初の数の意味が場合によって違った | 「548 件が該当（全 6,552 件） · 先頭 30 件を表示中」に統一した（`lib/catalog-status.ts`） |
| 中 | 全件 Poster の学会（icml-2026）で「all 6552」「Poster 6552」の意味のない 2 つのボタンと「0 Oral」が出る | 種類が 1 つだけならボタンを隠し、Oral 0 件の数字も出さない（URL で種類を指定したときは、外せるようにボタンを出す）。「all」は「すべて」に変えた |
| 中 | 要旨のない論文が多い学会（iclr-2025 は 18%、cvpr-2026 は 28%）で、それを外す手段がない | 「要旨あり」ボタンを追加した（URL `abs=1`、要旨のない行がある学会だけ）。冒頭に「要旨あり N」も表示する |
| 中 | 一覧のページから他の学会へ移れない（トップに戻るしかない） | 冒頭に「他の学会を見る」（`<details>`。JS なしでも開ける）を追加した。今の学会には `aria-current` を付けた |
| 中 | Oral/Poster の札がカードの高さいっぱいに伸びて、縦長の空の枠に見える。スマホでは札の列が約 60px を取り、タイトルが狭い | 札を `self-start` にした。スマホでは札をタイトルの上に置く |
| 中 | 詳細を開いても著者が 1 行で切れたまま | 選んだカードでは著者を全員表示する |
| 中 | 選んだカードの背景（surface-2）の上で、12px のリンク（OpenReview / PDF など）のコントラストが 4.17:1 で 4.5:1 に届かない | 選んだカードのリンクを accent-strong（7:1 以上）にし、下線を付けた |
| 中 | 「+N タグ」の `aria-controls="tag-chips-tail"` が存在しない id を指していた。「内容を見る」が 30 個同じ名前で並び、読み上げで区別できない | 残りのタグを包む要素に `useId` の id を付けた。開くボタンを「詳細を開く」（閉じるボタン「詳細を閉じる」と対）に変え、`aria-describedby` で論文タイトルを結び付けた |
| 中 | JS なしの一覧: 見出しが slug（`icml-2026`）のまま。タイトルがリンクに見えない（下線なし・本文と同じ色）。ページ番号が小さくて押しにくい | 表示名（ICML 2026）にした。タイトルに下線を付けた。ページ送りに「← 前へ / 次へ →」を足し、44px 以上の押せる大きさにした。行の HTML は変えていない（parity テストはそのまま通る） |
| 中 | 書き出しボタンが並び替えより前にあり、主な操作の間に割り込んでいた | ツールバーの順を「フィルタ解除 → 並び替え → BibTeX / CSV / URL」にした。書き出しボタンには件数入りの `aria-label` を付けた |

### 残したこと（低）

- `papers.json` が大きい（icml-2026 は展開後 7.0MB、圧縮後 1.67MB。要旨が約 3 割）。遅い回線では最初の結果まで数秒かかる。一覧用の軽いファイル（タイトル・著者・タグ・リンク・要旨の先頭）と検索用の要旨に分ければ、最初の表示を早くできる。pipeline（`buildPagesCli`）と `copy-data` の変更が要るので別の項目にする。読み込み中の表示に進み具合（何 MB 中何 MB）を出すのも同じ時に検討する。
- タイトルのリンク色（accent）が全カードで続き、画面が赤っぽく重い。サイト全体の色の決め方の話なので、ここでは変えない。
- 「続きを読む」（その場で要旨のプレビューを広げる）と「詳細を開く」（全文の要旨と系譜を読み込む）の 2 つの操作が近くにあり、違いが分かりにくい。1 つにまとめる案は history の復元（M8b）に関わるので別にする。
- 要旨の出典表示（CC BY の帰属表示）が一覧の各カードで 1〜2 行を取る。帰属表示は規約上必要（51 を参照）なので残した。短い形式にできるかは規約の確認と一緒に決める。
- PC で sticky の絞り込み欄の下に、Tab で移動したフォーカスが隠れることがある（WCAG 2.4.11）。`scroll-padding-top` を足す案がある。
- 「+N タグ」で開いたタグを閉じるボタンがない。タグ候補は上位 18 個だけで、それ以外のタグはカードのタグから選ぶしかない。
- トラック（分野）や「コードあり」の絞り込みは、`papers.json` にその列がない（`github_stars` はすべて 0）ので入れていない。
- JS なしの一覧は 1 ページ約 0.9MB（3,000 行）で、スマホでは重い。`NOJS_ROWS_PER_PAGE` を下げるときは pipeline の `paperLinksGate.ts` と同時に変える。
- acl-2026 は `CATALOG_COPY` に表示名がなく、見出しと切り替えに slug（`acl-2026`）のまま出る。`lib/catalog-copy.ts` に 1 行足す。
- 検索は今も部分一致だけで、語形の違い（"transformer" と "transformers"）や表記ゆれは吸収しない。
