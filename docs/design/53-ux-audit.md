## 系譜ページ

対象は `/themes/?theme=<slug>`（`components/themes/*`、`lib/themes-export.ts`）。ビルド済みサイト（`apps/web/out`）を 375px と 1280px で操作して確認し、graph-neural-network（34 論文・141 関係）、flash-attention、mixture-of-experts、vision-transformer で試した。重要度は 高 / 中 / 低 の 3 段階。範囲外として残した項目は最後の表に理由を書いた。

### 指摘と対応

| # | 重要度 | 指摘 | 対応 |
|---|---|---|---|
| 1 | 高 | スマホでは家系図（1868×2632px）が等倍のまま 343px 幅の枠に入り、カードが 1 枚しか見えない。拡大縮小の手段がない | 縮小・拡大・「全体」のボタンを付けた。SVG は viewBox を保ったまま `width`/`height` 属性だけを変える（インライン style は使わない）。640px 未満では 65% で開く。マウスでは背景のドラッグで移動できる |
| 2 | 高 | 家系図の `<svg role="img">` のせいで、中のカードと線（`role="button"`）がスクリーンリーダーから見えなかった（img の子要素は表示用として扱われる） | `role="group"` に変え、ラベルを付けた |
| 3 | 高 | 線の色（関係の種類）の凡例がどこにもない。本流・土台・発展・根拠の説明が 3 か所に散らばり、言い回しも揃っていない | 「この図の読み方」を新設した（ことば 4 語・線の色 6 種・カードの印・監査の区分）。初回は開いた状態で表示し、閉じたら `pp.theme.onboarded` に記録する。横軸のコーチマークと、散らばっていた説明文は削除した |
| 4 | 高 | カードをタップすると外部サイト（arXiv / DOI）に飛ぶ。家系図からは土台と発展を開けず、プルダウンでしか選べない | カードを「論文を選ぶ」ボタンにした（`aria-pressed`、もう一度押すと解除）。選ぶと図の下に「選択中: … 土台 n 本・発展 m 本」を出す。論文へのリンクは土台・発展パネルと根拠パネルに残っている |
| 5 | 高 | 根拠パネルが土台・発展パネルの下に開くため、スマホでは画面外になる | 640px 未満では画面下からのシート（最大 65vh、Esc と ✕ で閉じる）にした。それ以上の幅では図の直下に表示する。非モーダルなのでフォーカスは閉じ込めない。開いたときは見出しへ、閉じたときは開いた要素（線・「根拠」ボタン）へフォーカスを戻す |
| 6 | 中 | 操作バーが 4 段に分かれていた（横軸 6 個・書き出し 6 個・表示・本流） | 1 段にまとめた: 表示 / 本流 / 並べ方（`<select>`）/ 絞り込み / 書き出し・共有（`<details>` のメニュー）/ ⌨。並べ方の意味は選択欄の下に 1 行で出す |
| 7 | 中 | 横軸のラベル（「log」「中心」「新規」）が初めての人には分からない | 選択肢の名前を意味の分かる言葉にした（例:「研究の流れでまとめる」「会議の格」）。カード左端の色の意味も説明文に入れた |
| 8 | 中 | 見出しの階層: h1 が汎用の「テーマ別の系譜（時系列の家系図）」で、テーマ名はギャラリーのカードにしか出ていなかった | h1 を「<テーマ名> の系譜」にした。その下に、監査の区分、件数の 1 行（キーワードは件数ではなく中身を表示）、テーマの切り替え（全 N 件）の順に並べた。依頼ボタンはパンくずの行に移した |
| 9 | 中 | 「新着」と「コードとモデル」が常に開いていて、ページが長い（375px で 7,500px） | どちらも閉じた `<details>` にし、要約に件数を出す（375px で約 2,600px） |
| 10 | 中 | 線の当たり判定が 14px でタッチしにくい。年×被引用の点も半径 4.5px | タッチ端末（`pointer: coarse`）では線の当たり判定を 26 にした。点の周りには半径 14 の透明な当たり判定を足した |
| 11 | 中 | 文字のコントラスト: `text-accent` の小さいリンクが `surface-2` の上で 4.16:1（基準は 4.5） | 系譜ページのリンクは `text-accent-strong`（約 7:1）に統一した |
| 12 | 中 | キーボード操作: 図の中のタブ停止が 175 か所（線 141 + カード 34）あり、図の後ろへ進めない | 「家系図を飛ばして一覧へ」スキップリンクを付けた（フォーカスしたときだけ見える） |
| 13 | 中 | 書き出し: 拡大縮小を入れると、SVG / PNG の大きさが表示倍率に引きずられる | 書き出しは常に viewBox の大きさ（実寸）にした（`svgNaturalSize`） |
| 14 | 低 | 横にスクロールすると年のラベルが見えなくなる | 年ラベルを左端に固定した（`data-year-rail`。SVG の `transform` 属性で縦スクロールと倍率に追従する） |
| 15 | 低 | タップでもホバー用のポップオーバーやツールチップが開き、図を隠す | マウスの pointerenter と、キーボードフォーカス（`:focus-visible`）のときだけ開くようにした。ホバーのポップオーバーは操作できる要素を持たないので、`role` を dialog から tooltip に変えた |
| 16 | 低 | キーボードショートカットのダイアログ（`aria-modal`）がフォーカスを移さず、閉じ込めもしない。開くボタンもない | 開いたら「閉じる」へフォーカスを移し、Tab はダイアログの中にとどめ、閉じたら元の場所へ戻すようにした。操作バーに ⌨ ボタンを足した（640px 以上） |
| 17 | 低 | 本流の「切」が分かりにくい | 「オフ」にした |
| 18 | 低 | 本流ではない線を 0.3 まで薄くしていたので、背景の関係がほとんど見えない | 0.45 にした（本流の強調なしのときは 0.75） |
| 19 | 低 | スマホでテーマのギャラリーが横にスクロールできることに気づきにくい | 「横にスクロールできます →」を出した（640px 未満のみ） |
| 20 | 低 | 読み込み中の表示が低く、データが届くとページの高さが大きく変わる（CLS） | 読み込み中の領域を `min-h-[80vh]` にした |
| 21 | 低 | 依頼フォーム（約 550 行）が、開かなくても最初に読み込まれる | `React.lazy` で別チャンクにした（8 KB）。/themes の First Load は 155 kB から 154 kB に減った。新機能を足したあとの値 |
| 22 | 低 | 小さいタップ対象（✕、絞り込みの解除、書き出し）がある | 操作バー・拡大縮小・パネルのボタンを 36px 以上にした。375px で計測し、36px 未満は 0 件だった |
| 23 | 低 | 土台・発展パネルの説明文が長い。「選択を解除」が 2 か所にあった | 説明を 1 文に縮め、解除ボタンはパネルの中の 1 つだけにした |

### 範囲外として残したもの

| 項目 | 理由 |
|---|---|
| `lineage-quality-v1.json`（129 KB）を毎回取得している | 公開判定（SCR-32）の正本で、テーマごとに切り出すとパイプラインのデータ契約と promote の一致テストの変更になる。ページ側の修正ではない。テーマ用の小さい要約ファイルを作るのは別項目で扱う |
| `lineage.json`（GNN で 221 KB。Pages が圧縮して配信する） | sha256 が監査に結び付いているので、ページ側では中身を削れない |
| Web フォント 13 ファイル（約 700 KB） | サイト共通の `app/layout.tsx` の問題で、系譜ページだけでは直せない（別の節の担当） |
| 2 本指のピンチズーム | ブラウザ標準のページ拡大と衝突する。ボタンとドラッグで代わりになる |

### UI での確認（ビルド済みサイト、375px と 1280px）

両方の幅で、次をすべて UI 操作で確認した。

- テーマの切り替え（ギャラリー）と、ブラウザの戻る / 進む
- カードの選択（`?focus=` が付き、選択中バーが出る）
- 線をクリックして根拠パネルを開く（375px ではシート）。Esc と ✕ で閉じ、フォーカスが戻る。Enter でも開く
- 本流の 強調 / 本流だけ / オフ（GNN の場合、線は 141 → 11 → 141）
- 表示の 家系図 / 年×被引用（`?view=timeline`）。点を選ぶと土台・発展が出る
- 土台・発展パネル。行の「根拠」で根拠パネルが開く
- 2 本をつなぐ経路（`?to=`）。再読み込みしても選択と経路が戻る
- 書き出し: BibTeX / CSV（論文）/ CSV（関係と根拠）/ SVG / PNG の 5 ファイルが保存される。SVG は縮小表示中でも実寸
- URL のコピー: 実際のクリックでクリップボードに入ることを確認
- 誤りの報告リンク: GitHub の Issue テンプレートに値が入った状態で開く
- 新着の開閉と Atom リンク（200 `application/xml`）
- コード / HF の印
- 絞り込みと並べ方の URL（`?q=&xaxis=`）を再読み込みで復元できる

E2E（Playwright）の担当者向けに、主な流れと安定した手がかりを挙げる。

| 流れ | 手がかり |
|---|---|
| テーマの切り替え | `getByRole('region', {name:'テーマ一覧'})` の中のリンク。h1 にテーマ名が入る |
| カードの選択 | `getByRole('group', {name:/時系列家系図/})` の中の `getByRole('button', {name:/土台と発展を表示/})`。結果は `[data-selected-paper-bar]` に出る |
| 根拠 | `line[role=button]`（名前は「関係ラベル: …（Enter で根拠を表示）」）、`getByTestId('edge-evidence-panel')`、`getByRole('button', {name:'根拠パネルを閉じる'})` |
| 本流 | `[data-main-path-toggle]` の中のボタン 強調 / 本流だけ / オフ |
| 表示 | `[data-view-toggle]` の中のボタン 家系図 / 年×被引用 |
| 並べ方 | `getByRole('combobox', {name:'並べ方'})` |
| 拡大縮小 | ボタン 縮小 / 拡大 / 全体（`[data-zoom-controls]`） |
| 書き出し・共有 | `[data-export-menu]` の summary、`[data-export=bibtex|nodes-csv|edges-csv]`、画像（SVG）/ 画像（PNG）、`[data-share-url]`、結果は `[data-share-status]` |
| 土台・発展と経路 | `[data-prior-derivative]`、`[data-neighbor-select]`、`[data-path-select]`、`[data-lineage-path-result]` |
| 読み方 | `[data-reading-guide]`（`<details>`） |
| 新着・コード | `getByRole('region', {name:/新着/})`、`getByRole('region', {name:'コードとモデル'})`、`[data-feed-link]`、`[data-badge=code|hf]` |
