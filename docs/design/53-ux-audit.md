# 53 UI/UX 点検（2026-10-12）

ページの担当ごとに節を分ける。各節は単独で読めるようにする。

## トップ・共通

対象: トップ（`/`）、全ページ共通のヘッダー・フッター、`/how-it-works/`（仕組み・出典・プライバシー）、404。テーマ依頼フォームは `/themes/` の中にあるので、テーマの節で扱う。

方法: 静的書き出し（`apps/web/out`）を手元で配信し、ブラウザで幅 375px（スマホ）と 1280px（PC）を表示して確認した。あわせて、タップ領域の大きさ・見出しの構成・読み込むファイルとサイズ・CLS・メタタグを DOM と Performance API で測り、色のコントラストはデザイントークン（OKLCH）から WCAG の比を計算した。

### 残したもの

- ダークモード（`prefers-color-scheme`）がない（`color-scheme: light` で固定）。理由: トークンを切り替えると全ページに効くが、系譜のグラフ（`LineageTree.module.css` に直書きの OKLCH がある）や学会カタログは別の担当のページで、合わせて確かめないと読めない色の組み合わせが出る。この節の範囲（トップ・共通）だけでは閉じないので、全ページをまとめて点検するときに扱う。

### 操作の確認（ビルド結果、幅 375px と 1280px）

ブラウザで実際にクリック・キー入力して、次の流れがどちらの幅でも動くことを確かめた。横スクロールはどのページにもない。

1. Tab で「本文へスキップ」が左上に出る（フォーカスの枠あり）。Enter で `#main-content` に移り、次の Tab は本文の最初のリンクに進む。
2. ヘッダーの「探す / 学会 / 系譜 / 仕組み」で各ページに移り、移った先で該当の項目が現在地（`aria-current="page"`）になる。別のページから「学会」を押すと、トップの学会カタログの位置が表示される（#20 で修正）。
3. トップの案内文の「学会カタログ」「テーマ別の系譜」で、それぞれの節へ移る。
4. 例のチップ（diffusion など）を押すと、検索欄に入り、URL が `?q=…` になり、候補が出る。↓ で候補を選び、Enter でその論文の学会カタログ（`/<学会>/?paper=…`）に移る。Esc で候補を閉じる。1 文字だけ入れると「2 文字以上で検索します。」と出る。
5. 「検索した後は？」がクリックでも Enter でも開閉する。
6. 学会カタログのタイルで `/<学会>/` に移る。
7. テーマ別の系譜のカードで `/themes/?theme=<slug>` に移る。「テーマの一覧・依頼」「線の色の意味」で `/themes/`・`/how-it-works/` に移る。
8. フッターの「出典とライセンス」で `/how-it-works/#credits` の位置に移る。
9. 404 ページ（存在しない URL）のリンクで、トップ・学会カタログの一覧・テーマ別の系譜に移る。
10. 仕組みページの「PaperPilot でできること」のリンクと「公開中の系譜を見る」で、それぞれのページに移る。

E2E（`apps/web/e2e`）向けのセレクター: ランドマークとアクセシブルな名前で選べる。`banner`、`navigation`「グローバル」（リンク名 探す・学会・系譜・仕組み）、`contentinfo` の `navigation`「サイト情報」、`combobox`「タイトル・著者・タグで横断検索」、`listbox`「検索結果」、`button`「diffusion」など、`region`「学会カタログ (N)」、`region`「テーマ別の系譜」、`region`「PaperPilot でできること」、`navigation`「パンくずリスト」、404 の `main` 内のリンク。id（`#s0-confs`・`#s0-lineages`・`#s0-lineages-list`・`#s0-search-input`）も変えていない。

コンポーネントの操作テスト（@testing-library/react）: `test/landing/landing-ui.test.tsx`（件数と学会リンク、チップ→検索→候補→↓→Esc、1 文字のとき、ハッシュ付きで来たときの表示、自動フォーカス、「検索した後は？」の開閉、棚の表示・失敗・遅延取得・4 秒の上限、ビルド時の一覧がないときの取得）、`test/misc/site-chrome-ui.test.tsx`（ヘッダーの現在地とフォーカス、フッターのリンク、404 のリンク、仕組みページの案内・パンくず・小見出し）。

## 系譜ページ

対象は `/themes/?theme=<slug>`（`components/themes/*`、`lib/themes-export.ts`）。ビルド済みサイト（`apps/web/out`）を 375px と 1280px で操作して確認し、graph-neural-network（34 論文・141 関係）、flash-attention、mixture-of-experts、vision-transformer で試した。重要度は 高 / 中 / 低 の 3 段階。範囲外として残した項目は最後の表に理由を書いた。

### 範囲外として残したもの

| 項目 | 理由 |
|---|---|
| `lineage-quality-v1.json`（129 KB）を毎回取得している | 公開判定（SCR-32）の正本で、テーマごとに切り出すとパイプラインのデータ契約と promote の一致テストの変更になる。ページ側の修正ではない。テーマ用の小さい要約ファイルを作るのは別項目で扱う |
| `lineage.json`（GNN で 221 KB。Pages が圧縮して配信する） | sha256 が監査に結び付いているので、ページ側では中身を削れない |
| Web フォント 13 ファイル（約 700 KB） | サイト共通の `app/layout.tsx` の問題で、系譜ページだけでは直せない（別の節の担当） |
| 2 本指のピンチズーム | ブラウザ標準のページ拡大と衝突する。ボタンとドラッグで代わりになる |

### UI での確認（ビルド済みサイト、375px と 1280px）

- カードの選択（`?focus=` が付き、選択中バーが出る）
- 線をクリックして根拠パネルを開く（375px ではシート）。Esc と ✕ で閉じ、フォーカスが戻る。Enter でも開く
- 本流の 強調 / 本流だけ / オフ（GNN の場合、線は 141 → 11 → 141）
- 表示の 家系図 / 年×被引用（`?view=timeline`）。点を選ぶと土台・発展が出る
- 土台・発展パネル。行の「根拠」で根拠パネルが開く
- 2 本をつなぐ経路（`?to=`）。再読み込みしても選択と経路が戻る
- 書き出し: BibTeX / CSV（論文）/ CSV（関係と根拠）/ SVG / PNG の 5 ファイルが保存される。SVG は縮小表示中でも実寸
- URL のコピー: 実際のクリックでクリップボードに入ることを確認
- 誤りの報告リンク: GitHub の Issue テンプレートに値が入った状態で開く
- 新着の開閉と Atom リンク（200 `application/xml`）
- コード / HF の印
- 絞り込みと並べ方の URL（`?q=&xaxis=`）を再読み込みで復元できる
