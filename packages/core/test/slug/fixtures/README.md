# Fixture provenance

The expected outputs in this directory were generated by the Python
reference implementation through `gen.py`. That generator, and the
whole Python codebase it called into, was deleted in Tier C
(docs/migration/p5-plan.md §6.3), so these outputs are now frozen
contracts for the TypeScript port: never edit them by hand, and do not
expect to regenerate them. To read the original generator, use git
history: `git log --diff-filter=D --oneline -- packages/core/test/slug/fixtures/gen.py` and then
`git show <commit>^:packages/core/test/slug/fixtures/gen.py`.

`worker-slug-expected.json` is the frozen record of the old
`worker/slug.js::themeSlug()` on the same probes. Its generator,
`gen-worker-expected.mjs`, was deleted in Tier C together with
`worker/` (it needed the real `worker/slug.js` to run); the JSON is a
permanently frozen contract.
